# car-management-pern

## Installation Run Local

```bash
cd api
cp .env.example .env
npm install
npm run db:migrate
npm run db:start
```

```bash
cd web
npm install
```

```bash
cd api && npm run dev   # http://localhost:3000
cd web && npm run dev   # http://localhost:5173
```

- React
- Express

- Ant Design
